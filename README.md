# FSS 图片转 DXF

浏览器内将二维 FSS 图案识别为毫米单位的闭合 CAD 轮廓。无需后端服务，图片不离开本机。黄色金属与蓝色介质可自动识别，也支持原图点击取色。

## GitHub Pages

此仓库根目录的 `index.html` 即完整网站。进入仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，然后选择 **main / (root)** 并保存。页面网址通常为 `https://<账号>.github.io/<仓库名>/`。

## 使用

1. 打开网站，上传 PNG/JPG/WebP/BMP 图案。输入区显示原图，可直接点金属取色。
2. 设置单元或图案外接框的实际宽高（mm），核对二值图与 DXF 轮廓。
3. 预览可点选线段查看毫米长度，或打开全部标注；完整线段数据可导出 CSV。
4. 点击 **导出 DXF 图案** 即开始下载。若浏览器限制下载，可尝试 **直接下载 DXF 文件** 或 **通过系统对话框另存为**；仍不成功时展开 DXF 文本并复制为 `.dxf` 文件。

坐标位于 XY 平面，Z=0，DXF 2000，单位 mm；外轮廓和孔洞分别在 `METAL_OUTER`、`METAL_HOLE` 图层。CST 导入曲线后，按需要构面并扣除孔洞。斜直线自适应修正识别长斜线上的像素阶梯和小幅阈值毛刺，独立验证每个修正候选；验证内容包括轮廓自交、外接尺寸、孔洞及金属岛数量，并保护双向连续的窄缝和细线。局部修正失败不会影响其他长斜线，参数报告中记录被修正的线段数量及移除的阶梯顶点。拟合基于位图边缘，不能恢复原始 CAD 的精确设计尺寸。

```bash
node geometry.test.cjs
```

测试覆盖闭合轮廓、孔洞、黄蓝图案、直线拟合、像素细缝和线段尺寸。界面为纯前端，无构建命令。


## 手动点线编辑

自动识别完成后，在右侧“手动点线编辑”中点击 **开启编辑**。可在“选择顶点 / 线段”和“连接两个顶点”两种工具之间切换：

1. **选择顶点并删除**：自动以一条直线连接其相邻两个顶点，适用于删除斜边多余的阶梯拐点。
2. **选择线段并删除**：当前闭合轮廓变为一条带缺口的开放折线，缺口端点以橙色显示；选择“连接两个顶点”，依次点击两个端点可重新闭合。**存在开放轮廓时禁止 DXF 导出**。
3. **连接两个顶点**：同一闭合轮廓上，可用直线替换两点之间长度较短的旧路径（其中间顶点会删除）；开放折线的两个端点可用于闭合。连接必须通过自交、方向以及其他孔洞/金属岛冲突检查。
4. **在线段中点加顶点**：为需要手动重构的位置补充可选顶点。
5. **撤销 / 重做 / 恢复自动轮廓**：每次操作均可撤销。改变图片裁切、颜色或二值化参数会重新生成轮廓并清除当前手动编辑历史。

鼠标滚轮可放大至 16 倍，按住 **Alt + 鼠标拖动** 平移画面；也可以使用编辑栏放大、缩小和适应视图按钮。键盘可使用 Ctrl/Cmd+Z、Ctrl/Cmd+Y 和 Delete。为精确选择只有 1–2 个源图像素间距的顶点，建议先放大再点击。

所有改动保留在**像素坐标轮廓**中，后续修改单元实际尺寸时仍可重新缩放。尺寸表、预览和 DXF 均来自同一份顶点数据；修改时不自动改变原图像素遮罩。对于 FSS 的关键狭缝或局部尖角，请在导出后结合 CAD 软件检查实际线宽、孔洞和连通关系。


## 近似对称检测与镜像直线优先修复

在 **识别金属区域 → 对称辅助直线修复** 中，默认启用「自动检测并优先对称修正」。程序从二值化的**金属像素**计算图案关于金属外接框中心的三个候选对称关系：

- **左右镜像**（垂直对称轴）、**上下镜像**（水平对称轴）以及 **180° 中心对称**。
- 各自的吻合度以金属像素镜像后仍为金属的比例表示。默认要求达到 **94%**；可将阈值调节为 85%～99%，高阈值更保守。
- 对达到阈值的对称关系，优先寻找已经拟合成直线的长斜边，并映射到对称位置。**只有目标位置确有贴近该直线的阶梯短线段**，才尝试以直线替换冗余顶点；若端点足够接近且不改变外接尺寸和拓扑，则优先使用精确镜像坐标，否则保持原端点并仅修复直线。
- 每次拟合检查轮廓自交、方向、其他金属岛和孔洞碰撞、金属连通块与孔洞数量、边界像素变化以及细窄线条保护。不符合条件的局部会保持原样，再走原有逐段拟合流程。
- 「仅检测，不修改轮廓」可用于核对对称评分；「关闭对称修正」保留原有自动拟合行为。**精确像素边界**模式不会改动像素轮廓。
- 参数 JSON 包含各类对称评分、检测到的对称类型，以及对称修复的线段数、移除顶点数及使用精确镜像坐标的线段数。网页同时显示判定结果。

**注意**：近似对称是来自位图的统计判断，不能证明几何设计必然对称。刻意设计的非对称开槽、倒角或制造公差可能造成镜像不合适；应优先提高阈值或改用「仅检测」，并利用手动点线编辑与 CAD 尺寸检查最终几何。


## 生成导入图案的 Python 代码

在 **05 生成导入图案的 Python 代码** 面板中，选择输出类型并点击“生成当前图案代码”，随后可复制或下载 \`.py\` 文件。**代码直接读取网页当前的闭合轮廓与毫米坐标**，因此手动删除顶点、拉直斜边、修改孔洞和独立金属岛后，会与 DXF 导出使用同一份几何数据。存在未闭合轮廓时禁止生成；尺寸改变后必须重新生成，防止复制过期代码。所有处理仍在浏览器本机完成。

- **PyPSSFSS 代码**：导出最终轮廓顶点，使用偶奇填充规则在 32、64、128、256 或 512 的正方形网格上采样 0/1 金属矩阵，再使用 \`pixels(P=..., patternmat=..., units=mm, clas="J")\` 创建 FSS 金属片。运行 Python 脚本先生成 \`imported_fss_pixels.csv\`；将 \`RUN_SOLVER = True\` 后可调用 PyPSSFSS 正向求解。**仅支持正方形单元**，矩形周期请使用 DXF 代码；金属像素化会近似斜边、细缝及小孔，生成代码不代表已验证任何 S 参数。
- **ezdxf/CST 代码**：使用最终 XY 毫米坐标和闭合多段线，以 \`METAL_OUTER\`、\`METAL_HOLE\` 分层重新生成 \`imported_fss_pattern.dxf\`，可用于 CST 导入或二次 CAD 处理。需安装 \`ezdxf\`；导入后仍需按孔洞布尔构面。可以选择同步导出单元参考框。
- PyPSSFSS 脚本使用 \`pip install numpy pypssfss\`；ezdxf 脚本使用 \`pip install ezdxf\`。代码中的单层 PEC、空气环境和 8–16 GHz 设置仅是可启用的示例求解模板，实际分析前请设置介质层、频率与角度。

代码生成器为 \`codegen.js\`（Node 和浏览器共用逻辑），为了兼容离线下载页，其内容同时内嵌在 \`index.html\` 中。修改生成器时请同步这两份代码，并执行：

\`\`\`bash
node geometry.test.cjs
node codegen.test.cjs
\`\`\`


## 智能混合几何重建（2026-11）

默认模式为 **智能混合几何重建**：沿用已有的斜线修复及对称检测，对可靠的弧形轮廓增加圆拟合，逐条以像素覆盖、窄缝保护、无自交、孔洞与金属连通数量进行检查。未通过检查的候选圆弧恢复为原有线段，确保失败不影响其他部位。DXF 默认以闭合 LWPOLYLINE 和 bulge 参数导出圆弧；改为 LINE 导出时会使用采样后的折线。非等比例 X/Y 缩放下圆弧会转成采样折线，避免错误表达为圆。预览和导出的圆弧来自相同的曲线参数与密集采样坐标；手工编辑某条轮廓后，该轮廓的曲线实体会失效并安全回退为折线，撤销可恢复原曲线。

> 位图无法证明原始 CAD 的几何尺寸和曲率；建议在 CST 中复核关键缝隙、线宽和 S 参数。当前 Python ezdxf 代码生成器使用采样多段线，直接 DXF 导出才包含原生圆弧。


详见 [五种轮廓生成方法](METHODS.md)。

## 文献图标注排除与结构保护（v1.7）

在主预览上方的 **标注排除与结构保护** 面板中，先按主体金属颜色或灰度识别，再处理尺寸文字、数字、箭头、引线与虚线：

1. 用 **框选排除标注** 处理独立文字；用 **画笔排除标注** 沿与主体相连的引线涂抹。排除区显示红色，原图不会被修改。
2. 在关键细线、金属岛和空白缝隙上使用 **保护结构 / 间隙**。蓝色区域保留当前阈值 / 颜色识别出的原始金属与空白，并阻止排除、补绘和小区域去噪修改它。要改动保护区，先用 **恢复原始识别 / 解除保护** 清除该处保护。
3. 标注遮挡金属时，可使用绿色 **补绘金属缺口**，然后在参考图重绘中调整直线 / 圆弧。补绘是用户指定的几何修改，不推断被完全遮挡的设计。
4. **检测疑似标注 / 小区域** 按连通区域大小和细长形状提出候选，默认不勾选任何项；逐项确认后排除或保护。该功能不是 OCR，也不能自动识别与主体相连的文字 / 引线。真实小金属岛可能被列为候选；排除时只移除候选自身像素，不擦除整个外接矩形。
5. 支持 1～16 倍缩放、Alt 拖动平移、撤销 / 重做以及可撤销的“恢复全部区域”。可暂时关闭清理对照原始识别。新图片会清空旧图的操作。

清理在轮廓提取、去噪、对称和圆弧拟合之前执行。五种生成方法及兼容方法、二值预览、点线编辑、参考图重绘、DXF、CSV 和 Python 均使用同一份清理后结构。后续拟合 / 编辑 / 导出不得重新进入排除区或改动保护区；不满足约束的自动拟合回退到清理后的像素边界。移除标注形成的金属岛 / 孔洞数量变化允许发生在清理阶段，后续拓扑检查以清理结果为基准。

操作以原始图片的归一化坐标保存；改变裁切和处理分辨率不会把清理区错误地移到新裁切原点。低分辨率处理仍可能丢失不足一个处理像素的细节。参数 JSON 的 `annotation_cleanup` 包含启用状态、全部操作与像素统计，目前不提供参数 JSON 的重新导入。

上传 SVG 并启用实际清理区域时，使用清理后的栅格轮廓，界面会明确提示原生曲线被近似；暂停清理即可恢复直接 SVG 导入。页面自动生成的尺寸文字、坐标原点和虚线预览框本身不属于 `METAL_OUTER` / `METAL_HOLE`，不要把预览截图中的这些标记重新当作原始结构。

修改模块后运行 `node scripts/sync-inline.cjs` 更新离线单文件，再运行五组回归：

```sh
node geometry.test.cjs
node advanced.test.cjs
node redraw.test.cjs
node codegen.test.cjs
node cleanup.test.cjs
```


## 绘图描边与真实金属线宽（v1.8）

**图片中线条的含义** 独立于五种轮廓生成算法：

- **填色金属区域：保留实际线宽**（默认）：金属区域的内外边界都是真实几何。对于灰色填充的文献图，选择填充色或调整阈值包含金属填充，避免只选中边缘描线。点击取色时会根据主体色与图片边缘背景的色差建议容差，避免浅色填充连同白色背景一起被选中；该值仍可手动调节。
- **边界描线：忽略绘图线宽，沿中心重建**：当输入前景仅是用于表达设计边界的细闭合描线时，将每条描线的内外两侧合成一次中心边界，再按嵌套关系恢复金属区域及孔洞。不是对整条真实金属带进行骨架化。

先清理文字、尺寸线、原点标记和周期参考框，再选择描线颜色 / 阈值。设置 **绘图描边最大宽度 / 原图 px**，以原图像素计；处理降采样时程序同步换算。过宽区域会保留原有宽度；真实细导线与绘图描边不能仅凭像素唯一判别，因此请按图义明确选择模式。描边双线修正示例用 4 px 绘图线表示一条金属带的内外两条设计边界：区域模式生成 4 条描线包络，中心模式得到 1 条金属外边界和 1 条孔洞边界。

中心线由描线两侧距离相等的位置重建，再栅格化供各轮廓算法使用；仍受图片分辨率和抗锯齿影响，不是原始 CAD 尺寸恢复。界面和参数 JSON 报告实际合并数、输入 / 输出边界数、宽区域保留数与未解决区域数。未闭合、分叉、交叠、多孔区域不会被猜测性合并；需先处理标注或手动重绘。保护区覆盖的描线不会被合并。

标注清理在描线解释前后保持有效；参考图重绘、尺寸、DXF、CSV、Python 使用同一份解释后的区域几何。SVG 启用描边中心模式时采用栅格重建并提示，避免原生 SVG 填色导入绕过该模式。转换参数增加 `boundary_mode`、`drawing_stroke_max_width_source_px`、`drawing_stroke`。

运行 `node stroke-boundary.test.cjs` 验证 2/4/6 px 绘图线宽得到同样的设计边界、真实宽金属带保护、圆 / 斜边、开线与分叉拒绝、清理保护、重绘、DXF/Python 和 Worker / 离线同步。


## 图案区域统一解释（v1.9）

默认 **图案区域：填色与附着描线合并**。图片只解释为图案与空白两类，轮廓线是同一图案区域的边界，不是第三类材料。流程为：填色内部 → 连接附着描线、剔除孤立边缘细条 → 单一二值图案区域 → 闭合点线边界 → 毫米尺寸和导出。DXF 不再分别追踪取色产生的主体与附着细条。

填色图按颜色取样时，先由选中像素中的填色内部建立种子，在限定的 **附着描线范围 / 原图 px** 内纳入相容的深色或中性深色描线；不跨越白色缝隙，也不把整幅图的深色像素一律作为金属。无填色内部的孤立细条 / 抗锯齿边缘不会作为独立图案导出。灰度图使用相同的内部种子和连接约束；新图片自动计算初始灰度阈值，避免灰色实体被固定 127 阈值漏掉。

原图存在真实细导线或小金属岛时，应使用保护笔保留，或切换 **精确颜色 / 灰度区域（兼容）** 对照。纯细线图若没有可靠填色内部，会保留精确像素并明确提示；闭合纯线框可使用原有的中心边界模式。空白保护、标注排除和补绘金属均优先于区域解释。R 字母、尺寸虚线和参考外框仍需使用标注清理 / 裁切，不会凭形状自动认定为辅助标记。已经被标注覆盖的真实几何也不会被无依据填补。

整合后的二值区域统一供五种算法、兼容算法、参考图重绘、点线编辑、尺寸表、DXF、CSV 和 Python 代码使用。原生 SVG 默认保持直接矢量导入；主动选择整体区域解释时改用栅格整合并提示。参数 JSON 的 `region_interpretation` 记录填色种子、补入描线像素、去除细条像素、范围和精确回退情况。

回归增加 `node region.test.cjs`：同一填色区域与深色描边、灰色抗锯齿外圈由三条原始包络重建为一条边界；逐边检查无重复；同时检查孔洞、1 px 白色缝隙、相邻浅蓝区域、保护小岛、补绘、无内部细线回退、所有轮廓算法、DXF / Python、Worker 与离线单文件同步。
