# FSS 图片转 DXF

浏览器内将二维 FSS 图案识别为毫米单位的闭合 CAD 轮廓。无需后端服务，图片不离开本机。黄色金属与蓝色介质可自动识别，也支持原图点击取色。

## GitHub Pages

此仓库根目录的 `index.html` 即完整网站。进入仓库 **Settings → Pages**，在 **Build and deployment** 中选择 **Deploy from a branch**，然后选择 **main / (root)** 并保存。页面网址通常为 `https://<账号>.github.io/<仓库名>/`。

## 使用

1. 打开网站，上传 PNG/JPG/WebP/BMP 图案。输入区显示原图，可直接点金属取色。
2. 设置单元或图案外接框的实际宽高（mm），核对二值图与 DXF 轮廓。
3. 预览可点选线段查看毫米长度，或打开全部标注；完整线段数据可导出 CSV。
4. 点击 **导出 DXF 图案** 即开始下载。若浏览器限制下载，可尝试 **直接下载 DXF 文件** 或 **通过系统对话框另存为**；仍不成功时展开 DXF 文本并复制为 `.dxf` 文件。

坐标位于 XY 平面，Z=0，DXF 2000，单位 mm；外轮廓和孔洞分别在 `METAL_OUTER`、`METAL_HOLE` 图层。CST 导入曲线后，按需要构面并扣除孔洞。斜直线自适应修正识别长斜线上的像素阶梯和小幅阈值毛刺，独立验证每个修正候选；验证内容包括轮廓自交、外接尺寸、孔洞及金属岛数量，并保护双向连续的窄缝和细线。局部修正失败不会影响其他长斜线，参数报告中记录被修正的线段数量及移除的阶梯顶点。拟合基于位图边缘，不能恢复原始 CAD 的精确设计尺寸。

## 验证

```bash
node geometry.test.cjs
```

测试覆盖闭合轮廓、孔洞、黄蓝图案、直线拟合、像素细缝和线段尺寸。界面为纯前端，无构建命令。


## 手动点线编辑

自动识别完成后，在右侧“手动点线编辑”中点击 **开启编辑**。可在“选择顶点 / 线段”和“连接两个顶点”两种工具之间切换：

1. **选择顶点并删除**：自动以一条直线连接其相邻两个顶点，适用于删除斜边多余的阶梯拐点。
2. **选择线段并删除**：当前闭合轮廓变为一条带缺口的开放折线，缺口端点以橙色显示；选择“连接两个顶点”，依次点击两个端点可重新闭合。**存在开放轮廓时禁止 DXF 导出**。
3. **连接两个顶点**：同一闭合轮廓上，可用直线替换两点之间长度较短的旧路径（其中间顶点会删除）；开放折线的两个端点可用于闭合。连接必须通过自交、方向以及其他孔洞/金属岛冲突检查。
4. **在线段中点加顶点**：为需要手动重构的位置补充可选顶点。
5. **撤销 / 重做 / 恢复自动轮廓**：每次操作均可撤销。改变图片裁切、颜色或二值化参数会重新生成轮廓并清除当前手动编辑历史。

鼠标滚轮可放大至 16 倍，按住 **Alt + 鼠标拖动** 平移画面；也可以使用编辑栏放大、缩小和适应视图按钮。键盘可使用 Ctrl/Cmd+Z、Ctrl/Cmd+Y 和 Delete。为精确选择只有 1–2 个源图像素间距的顶点，建议先放大再点击。

所有改动保留在**像素坐标轮廓**中，后续修改单元实际尺寸时仍可重新缩放。尺寸表、预览和 DXF 均来自同一份顶点数据；修改时不自动改变原图像素遮罩。对于 FSS 的关键狭缝或局部尖角，请在导出后结合 CAD 软件检查实际线宽、孔洞和连通关系。


## 近似对称检测与镜像直线优先修复

在 **识别金属区域 → 对称辅助直线修复** 中，默认启用「自动检测并优先对称修正」。程序从二值化的**金属像素**计算图案关于金属外接框中心的三个候选对称关系：

- **左右镜像**（垂直对称轴）、**上下镜像**（水平对称轴）以及 **180° 中心对称**。
- 各自的吻合度以金属像素镜像后仍为金属的比例表示。默认要求达到 **94%**；可将阈值调节为 85%～99%，高阈值更保守。
- 对达到阈值的对称关系，优先寻找已经拟合成直线的长斜边，并映射到对称位置。**只有目标位置确有贴近该直线的阶梯短线段**，才尝试以直线替换冗余顶点；若端点足够接近且不改变外接尺寸和拓扑，则优先使用精确镜像坐标，否则保持原端点并仅修复直线。
- 每次拟合检查轮廓自交、方向、其他金属岛和孔洞碰撞、金属连通块与孔洞数量、边界像素变化以及细窄线条保护。不符合条件的局部会保持原样，再走原有逐段拟合流程。
- 「仅检测，不修改轮廓」可用于核对对称评分；「关闭对称修正」保留原有自动拟合行为。**精确像素边界**模式不会改动像素轮廓。
- 参数 JSON 包含各类对称评分、检测到的对称类型，以及对称修复的线段数、移除顶点数及使用精确镜像坐标的线段数。网页同时显示判定结果。

**注意**：近似对称是来自位图的统计判断，不能证明几何设计必然对称。刻意设计的非对称开槽、倒角或制造公差可能造成镜像不合适；应优先提高阈值或改用「仅检测」，并利用手动点线编辑与 CAD 尺寸检查最终几何。


## 生成导入图案的 Python 代码

在 **05 生成导入图案的 Python 代码** 面板中，选择输出类型并点击“生成当前图案代码”，随后可复制或下载 \`.py\` 文件。**代码直接读取网页当前的闭合轮廓与毫米坐标**，因此手动删除顶点、拉直斜边、修改孔洞和独立金属岛后，会与 DXF 导出使用同一份几何数据。存在未闭合轮廓时禁止生成；尺寸改变后必须重新生成，防止复制过期代码。所有处理仍在浏览器本机完成。

- **PyPSSFSS 代码**：导出最终轮廓顶点，使用偶奇填充规则在 32、64、128、256 或 512 的正方形网格上采样 0/1 金属矩阵，再使用 \`pixels(P=..., patternmat=..., units=mm, clas="J")\` 创建 FSS 金属片。运行 Python 脚本先生成 \`imported_fss_pixels.csv\`；将 \`RUN_SOLVER = True\` 后可调用 PyPSSFSS 正向求解。**仅支持正方形单元**，矩形周期请使用 DXF 代码；金属像素化会近似斜边、细缝及小孔，生成代码不代表已验证任何 S 参数。
- **ezdxf/CST 代码**：使用最终 XY 毫米坐标和闭合多段线，以 \`METAL_OUTER\`、\`METAL_HOLE\` 分层重新生成 \`imported_fss_pattern.dxf\`，可用于 CST 导入或二次 CAD 处理。需安装 \`ezdxf\`；导入后仍需按孔洞布尔构面。可以选择同步导出单元参考框。
- PyPSSFSS 脚本使用 \`pip install numpy pypssfss\`；ezdxf 脚本使用 \`pip install ezdxf\`。代码中的单层 PEC、空气环境和 8–16 GHz 设置仅是可启用的示例求解模板，实际分析前请设置介质层、频率与角度。

代码生成器为 \`codegen.js\`（Node 和浏览器共用逻辑），为了兼容离线下载页，其内容同时内嵌在 \`index.html\` 中。修改生成器时请同步这两份代码，并执行：

\`\`\`bash
node geometry.test.cjs
node codegen.test.cjs
\`\`\`
